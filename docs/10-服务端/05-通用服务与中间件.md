# 05 通用服务与中间件

> 服务端「跨模块复用」的所有片段：全局 ValidationPipe、HttpExceptionFilter、helmet、CORS、PrismaService、分页 DTO 等。

## 1. 全局 ValidationPipe

文件：`server/src/main.ts`

```ts
app.useGlobalPipes(new ValidationPipe({
  whitelist: true,
  forbidNonWhitelisted: true,
  transform: true
}))
```

三个开关含义：

- **`whitelist: true`** — 自动剔除 DTO 中未声明的字段
- **`forbidNonWhitelisted: true`** — 若请求体含未声明字段，直接 400 报错（避免脏数据写入）
- **`transform: true`** — 启用 `class-transformer`，自动把 plain JSON 转成 DTO 类实例（支持 `@Type(() => Number)` 这类装饰器）

典型用法示例（来自 `server/src/admin-users/dto/query-user.dto.ts`）：

```ts
export class QueryUserDto extends PaginationDto {
  @IsOptional()
  @Type(() => Number)   // query string → number
  @IsInt()
  @Min(0)
  status?: number
}
```

## 2. HttpExceptionFilter

文件：`server/src/common/filters/http-exception.filter.ts`

```ts
@Catch()
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception, host) {
    const ctx = host.switchToHttp()
    const response = ctx.getResponse<Response>()
    const request = ctx.getRequest<Request>()

    const status = exception instanceof HttpException
      ? exception.getStatus()
      : HttpStatus.INTERNAL_SERVER_ERROR

    const payload = exception instanceof HttpException
      ? exception.getResponse()
      : { message: 'Internal server error' }

    const body = typeof payload === 'string'
      ? { statusCode: status, message: payload }
      : { statusCode: status, ...(payload as Record<string, unknown>) }

    if (status >= 500) {
      this.logger.error(...)
    }

    response.status(status).json({
      ...body,
      path: request.url,
      timestamp: new Date().toISOString()
    })
  }
}
```

要点：

- 所有未捕获的异常都会被此过滤器统一包装为 `{ statusCode, message | 其他, path, timestamp }`
- `status >= 500` 会自动用 NestJS `Logger.error` 打 ERROR 日志（含堆栈）
- 4xx 仅返回响应，不打日志
- `main.ts` 通过 `app.useGlobalFilters(new HttpExceptionFilter())` 注册

## 3. helmet

文件：`server/src/main.ts`

```ts
app.use(helmet())
```

默认开启的安全头（节选）：

- `X-Frame-Options: SAMEORIGIN`（防点击劫持）
- `X-Content-Type-Options: nosniff`
- `Strict-Transport-Security`（仅 HTTPS 下生效）
- `Referrer-Policy: same-origin`

如果前端需要内嵌 iframe 访问后台（例如 SSO 场景），需要单独放开 `frame-ancestors`。

## 4. CORS

```ts
app.enableCors({
  origin: (process.env.CORS_ORIGINS ?? 'http://localhost:5173')
    .split(',').map((s) => s.trim()).filter(Boolean),
  credentials: true
})
```

- 默认只允许 `http://localhost:5173`（移动端）
- 多 origin 用 `CORS_ORIGINS` 配置，逗号分隔
- 后台 `5174` 默认被拒绝，需显式加入：
  ```env
  CORS_ORIGINS="http://localhost:5173,http://localhost:5174"
  ```
- `credentials: true` 允许携带 Cookie；当前 Token 通过 `Authorization: Bearer` 传，未用 Cookie，但保留兼容

> 生产环境部署时务必用环境变量配置完整白名单，不要在代码里硬编码。

## 5. PrismaService

文件：`server/src/prisma/prisma.service.ts`

```ts
@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
  async onModuleInit() { await this.$connect() }
  async onModuleDestroy() { await this.$disconnect() }
}
```

要点：

- `PrismaModule` 在 `app.module.ts` 用 `@Global()` 注册，所有模块无需 `imports: [PrismaModule]` 即可注入
- 进程启动时自动连接，进程关闭时优雅断开

事务用法：

```ts
const [total, list] = await this.prisma.$transaction([
  this.prisma.order.count({ where }),
  this.prisma.order.findMany({ where, ... })
])

// 交互式事务
const order = await this.prisma.$transaction(async (tx) => {
  for (const it of items) {
    await tx.product.update({ where: { id: it.productId }, data: { stock: { decrement: it.quantity } } })
  }
  return tx.order.create({ data: { ...orderData, items: { create: items } } })
})
```

详见 `03-数据库Schema说明.md` 末尾的「Prisma 常用查询示例」。

## 6. 分页 DTO

文件：`server/src/common/dto/pagination.dto.ts`

```ts
export class PaginationDto {
  @IsOptional() @Type(() => Number) @IsInt() @Min(1) page?: number = 1
  @IsOptional() @Type(() => Number) @IsInt() @Min(1) pageSize?: number = 10
  @IsOptional() @IsString() @MaxLength(64) keyword?: string
}

export interface PaginatedResult<T> {
  list: T[]
  total: number
  page: number
  pageSize: number
  hasMore: boolean
}
```

典型用法：

```ts
// 后台用户列表
export class QueryUserDto extends PaginationDto {
  @IsOptional() @Type(() => Number) @IsInt() @Min(0) status?: number
}

async list(q: QueryUserDto): Promise<PaginatedResult<unknown>> {
  const page = q.page ?? 1
  const pageSize = q.pageSize ?? 10
  const [total, list] = await this.prisma.$transaction([...])
  return { list, total, page, pageSize, hasMore: page * pageSize < total }
}
```

前端对应类型：

```ts
// admin/src/api/types.ts
export interface PaginatedResult<T> {
  list: T[]
  total: number
  page: number
  pageSize: number
  hasMore: boolean
}
```

## 7. 路由前缀

```ts
// server/src/main.ts
app.setGlobalPrefix('api')
```

效果：

- 所有控制器路径前缀加 `/api`
- 前台控制器：`@Controller('products')` → `/api/products`
- 后台控制器：`@Controller('admin/orders')` → `/api/admin/orders`

## 9. Logger

NestJS 内置 `Logger`，主要使用点：

- `main.ts` 的启动日志：`Logger.log(\`Server running on http://localhost:${port}/api\`, 'Bootstrap')`
- `HttpExceptionFilter` 的 500 级别错误日志
- 各 service 可按需 `private readonly logger = new Logger(XxxService.name)`

示例：

```ts
import { Logger } from '@nestjs/common'

@Injectable()
export class MyService {
  private readonly logger = new Logger(MyService.name)

  doSomething() {
    this.logger.log('doing something')         // 普通
    this.logger.warn('careful')                // 警告
    this.logger.error('oops', exception.stack) // 错误（带堆栈）
  }
}
```
