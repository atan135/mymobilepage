# 02 部署步骤

## 1. 拉取代码

```bash
cd /opt
git clone <repo-url> mymobilepage
cd mymobilepage
git checkout main
```

## 2. 安装依赖

```bash
npm install
```

## 3. 配置环境变量

```bash
cp server/.env.example server/.env
nano server/.env   # 填入真实 DATABASE_URL + 强随机 JWT_SECRET
```

## 4. 数据库迁移 + 种子

```bash
# 应用所有 migration
npm run prisma:migrate

# 写入初始数据（默认账号 + demo 商品 / 订单 / 优惠券 / 评价 / 流水 / 设置）
npm run prisma:seed
```

> **生产环境首次部署**：seed 会创建默认账号，部署完成后**立即修改密码**（详见 04 上线清单）。

## 5. 构建三端

```bash
# 顺序无要求，可并行
npm run build:server   # 输出 server/dist
npm run build:admin    # 输出 admin/dist（静态站点）
npm run build:client   # 输出 client/dist（静态站点）
```

## 6. PM2 启动服务端

新建 `ecosystem.config.js`（项目根目录）：

```js
module.exports = {
  apps: [{
    name: 'mymobilepage-api',
    cwd: './server',
    script: 'dist/main.js',
    instances: 1,           // 单实例；如需 cluster 改成 'max'
    exec_mode: 'fork',
    env: { NODE_ENV: 'production' },
    max_memory_restart: '512M',
    out_file: '/var/log/mymobilepage/out.log',
    error_file: '/var/log/mymobilepage/error.log',
    time: true
  }]
}
```

```bash
mkdir -p /var/log/mymobilepage
pm2 start ecosystem.config.js
pm2 save
pm2 startup   # 设置开机自启（按提示执行返回的命令）
```

## 7. 部署静态站点

admin / client 产物是纯静态文件，直接放到 Nginx 服务的目录即可：

```bash
sudo mkdir -p /var/www/mymobilepage/{admin,client}
sudo cp -r admin/dist/* /var/www/mymobilepage/admin/
sudo cp -r client/dist/* /var/www/mymobilepage/client/
```

## 8. 配置 Nginx

参见 `03-Nginx与HTTPS.md`。

## 9. 验证

```bash
# 健康检查
curl https://yourdomain.com/api/admin/dashboard/overview   # 应返回 401（未登录，正常）

# 浏览器打开
https://yourdomain.com/admin/   # 后台登录
https://yourdomain.com/client/   # 移动端
```

## 10. 回滚

```bash
# 服务端回滚
cd /opt/mymobilepage
git checkout <previous-tag>
npm run build:server
pm2 reload mymobilepage-api

# 数据库回滚（谨慎）
# Prisma 不支持自动 down migration；建议在迁移前先备份 DB
```
