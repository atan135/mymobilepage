# 01 环境准备

## 服务器最低配置

| 项 | 最低 | 推荐 |
| --- | --- | --- |
| CPU | 1 核 | 2 核+ |
| 内存 | 1 GB | 2 GB+ |
| 硬盘 | 20 GB | 40 GB+（含日志 + 备份） |
| OS | Linux x86_64 | Ubuntu 22.04 LTS / Debian 12 |

## 软件清单

| 软件 | 版本 | 用途 | 安装 |
| --- | --- | --- | --- |
| Node.js | ≥ 20 LTS | 运行时 | `nvm install 20` 或 `apt install nodejs` |
| npm | ≥ 10 | 包管理 | 随 Node 一起 |
| PostgreSQL | ≥ 14 | 主数据库 | `apt install postgresql` |
| PM2 | ≥ 5 | Node 进程管理 | `npm i -g pm2` |
| Nginx | ≥ 1.18 | 反向代理 + 静态 | `apt install nginx` |
| certbot | 最新 | Let's Encrypt HTTPS | `apt install certbot python3-certbot-nginx` |

## 数据库准备

```sql
-- 以 postgres 超级用户登录
CREATE USER mymobilepage WITH PASSWORD 'STRONG_PASSWORD_HERE';
CREATE DATABASE mymobilepage OWNER mymobilepage;
GRANT ALL PRIVILEGES ON DATABASE mymobilepage TO mymobilepage;
```

## 端口规划

| 端口 | 服务 | 暴露 |
| --- | --- | --- |
| 80 / 443 | Nginx | 公网 |
| 3000 | NestJS | 仅内网（127.0.0.1） |
| 5432 | PostgreSQL | 仅内网（127.0.0.1） |

## 服务端环境变量

`server/.env`：

```env
# PostgreSQL 连接串
DATABASE_URL="postgresql://mymobilepage:STRONG_PASSWORD_HERE@127.0.0.1:5432/mymobilepage?schema=public"

# 服务端口（默认 3000）
PORT=3000

# 前后台 JWT secret —— **生产必改**为强随机串（`openssl rand -base64 64`）
JWT_SECRET="REPLACE_WITH_RANDOM_64_CHARS"
JWT_ADMIN_SECRET="REPLACE_WITH_DIFFERENT_RANDOM_64_CHARS"

# 运行环境
NODE_ENV=production
```
