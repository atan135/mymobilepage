# 01 移动端技术栈与启动

> `client/` 子项目的技术栈、目录约定、启动与构建。

## 1. 技术栈

| 维度 | 选型 |
| --- | --- |
| 框架 | Vue 3.5（Composition API） |
| 构建 | Vite 5 |
| 类型 | TypeScript 5 |
| 路由 | Vue Router 4（`createWebHistory`） |
| 状态 | Pinia（**未启用持久化插件**，仅 token / user 手写 localStorage） |
| UI 库 | Vant 5（`@vant/auto-import-resolver` 按需引入） |
| HTTP | `ofetch` 封装，baseURL `/api` |
| 样式 | px（**未引入 rem / vw 适配方案**） |
| 路径别名 | `@` → `src/` |

## 2. 入口与全局设置

文件：`client/src/main.ts`

```ts
import 'vant/lib/index.css'
import './styles/main.css'

const app = createApp(App)
app.use(createPinia())
app.use(router)
app.mount('#app')
```

要点：

- 没有像 admin 那样注册全局组件 / 指令
- Vant 组件通过 unplugin 自动按需引入，**不需要在 main.ts 里逐个 import**
- 没有 `pinia-plugin-persistedstate` —— 持久化由 store 内部手写 localStorage（详见 `03-状态管理与接口调用.md`）

## 3. 路由与守卫

文件：`client/src/router/index.ts`

### 路由结构

```
/login                            LoginView              公开
/                                 TabBarLayout           （4 个 tab）
  ├─ /home                        HomeView               requiresAuth: true
  ├─ /category                    CategoryView           requiresAuth: true
  ├─ /cart                        CartView               requiresAuth: true
  └─ /profile                     ProfileView            requiresAuth: true
/product/:id                      ProductDetailView      requiresAuth: true
/order/confirm                    OrderConfirmView       requiresAuth: true
/order/success                    OrderSuccessView       requiresAuth: true
/order/list                       OrderListView          requiresAuth: true
/order/detail                     OrderDetailView        requiresAuth: true
```

未匹配路由 → 重定向 `/home`。

### 全局前置守卫

```ts
router.beforeEach((to) => {
  const userStore = useUserStore()
  const requiresAuth = to.meta.requiresAuth === true

  if (requiresAuth && !userStore.isLoggedIn) {
    return { name: 'login', query: { redirect: to.fullPath } }
  }

  if (to.name === 'login' && userStore.isLoggedIn) {
    return { name: 'home' }
  }

  if (typeof to.meta.title === 'string') {
    document.title = `${to.meta.title} · 我的商城`
  }
})
```

> 与后台不同：移动端**所有需要登录的页面**都要求 `meta.requiresAuth: true`。后台的菜单权限则通过 `meta.permission` 控制。

## 4. HTTP 封装

文件：`client/src/api/request.ts`

```ts
export const request = ofetch.create({
  baseURL: '/api',          // 注意：没有 /admin
  timeout: 10_000,
  onRequest({ options }) {
    const token = localStorage.getItem('token')
    if (token) {
      const headers = new Headers(options.headers as HeadersInit | undefined)
      headers.set('Authorization', `Bearer ${token}`)
      options.headers = headers
    }
  },
  onResponseError({ response }) {
    if (response.status === 401) {
      localStorage.removeItem('token')
      localStorage.removeItem('user')
    }
  }
})

export const delay = (ms = 300) => new Promise((r) => setTimeout(r, ms))
```

要点：

- `baseURL = '/api'` — 与后台的 `/api/admin` 区分开
- 自动注入 `Authorization: Bearer <token>`（token key 是 `token`，不是 `admin-token`）
- 收到 401 自动清掉本地 token + user
- 提供 `delay(ms)` 工具函数（**死代码**——当前未被任何 api 调用，未来清理时可一起删除）
## 5. 关于当前阶段的接口调用

移动端**所有接口都已通过 ofetch 走真实后端**，由 `client/src/api/*.ts` 统一封装：

| 文件 | 真实接口 |
| --- | --- |
| `auth.ts` | `POST /api/auth/login`、`POST /api/auth/logout` |
| `banner.ts` | `GET /api/banners` |
| `product.ts` | `GET /api/categories`、`GET /api/products`、`GET /api/products/:id` |
| `order.ts` | `POST /api/orders`、`GET /api/orders/my`、`GET /api/orders/:id`、`PATCH /api/orders/:id/cancel`、`POST /api/orders/:id/confirm-receipt` |

> 注意：`request.ts` 中的注释 `当前阶段所有接口走本地 mock` 是早期版本遗留，**与实际代码不符**。当前所有 api 文件都直接调用 `request<T>(...)` 发起真实请求；`delay()` 也是死代码，未来清理时可一起删除。

登录页底部文案「演示版：任意非空用户名 / 密码均可登录」同样已过时——真实流程会经 `AuthService.login` bcrypt 比对密码，仅 seed 的 5 个测试账号（`alice~eve / user123`）能成功登录。

## 6. 启动与构建

通过根 `package.json` 的 workspaces 调用：

```bash
npm run dev:client          # 开发（Vite dev server）
npm run build:client        # 构建到 client/dist
npm run preview:client      # 预览构建产物
npm run type-check:client   # 类型检查
```

Vite 配置（`client/vite.config.ts`）：

- 端口：`5173`
- 主机：`0.0.0.0`（局域网可访问）
- 代理：`/api` → `http://localhost:3000`
- 自动导入：`unplugin-vue-components` + `VantResolver`
- 别名：`@` → `src/`

const tabs = [
