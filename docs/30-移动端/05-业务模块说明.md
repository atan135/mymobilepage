# 05 移动端业务模块说明

> 10 个页面按业务模块分组说明：首页 / 分类 / 商品详情 / 购物车 / 订单 / 我的。

## 1. 模块总览

| 模块 | 页面 | 主要交互 |
| --- | --- | --- |
| 首页 | `HomeView.vue` | 轮播 + 分类宫格 + 商品瀑布流 |
| 分类 | `CategoryView.vue` | 左侧分类 + 右侧商品 |
| 商品详情 | `ProductDetailView.vue` | 封面 / 价格 / 销量 / 描述 + 加入购物车 / 立即购买 |
| 购物车 | `CartView.vue` | 多选 + 调数量 + 删除 + 结算 |
| 订单确认 | `OrderConfirmView.vue` | 商品清单 + 收货人 + 备注 + 提交 |
| 下单成功 | `OrderSuccessView.vue` | 显示订单号 + 查看订单 / 继续购物 |
| 我的订单 | `OrderListView.vue` | 状态分段 + 列表 + 下拉刷新 |
| 订单详情 | `OrderDetailView.vue` | 状态进度 + 商品 + 收货人 + 操作（取消 / 确认收货） |
| 我的 | `ProfileView.vue` | 用户卡 + 菜单 + 退出登录 |
| 登录 | `LoginView.vue` | 用户名 + 密码 + 跳回 redirect |

## 2. 首页（HomeView）

文件：`client/src/views/HomeView.vue`

```ts
async function loadBanners() { banners.value = await listBanners() }
async function loadCategories() { categories.value = await listCategories() }
async function loadProducts() {
  const res = await listProducts({ page: page.value, pageSize: 10 })
  products.value.push(...res.list)
  if (!res.hasMore) finished.value = true
  else page.value += 1
}
```

UI 结构：

```
van-nav-bar (fixed, title="我的商城")
van-swipe (autoplay=4000, indicator-color="white")
  van-swipe-item → <img :src="banner.image">
van-grid (column-num=3, border=false)
  van-grid-item → 点击跳 /category?id=...
van-pull-refresh
  van-list (分页)
    van-card (商品行)
```

要点：

- `van-nav-bar fixed` + `padding-top: 46px` 让内容不被遮挡
- `van-pull-refresh` + `van-list` 实现下拉刷新 + 上拉加载更多
- `listProducts` 返回 `PaginatedProducts`，按 `hasMore` 控制 `finished`

- **公开设置加载**：onMounted 调 `listPublicSettings(['site_name', 'customer_service_phone'])`，影响 nav-bar 标题与底部客服电话卡片
- **配套 API**：`client/src/api/settings.ts`（baseURL 已含 `/api`，无需 token）## 3. 分类（CategoryView）

文件：`client/src/views/CategoryView.vue`

- `van-sidebar` 左侧分类列表，`v-model` 绑定 `activeIndex`（computed：在分类 id 与 children 数组下标之间互译；Vant 4 sidebar 的 v-model 是下标不是业务主键），`activeId` 才是真正参与筛选的分类主键
- 右侧 `van-list` 商品流
- `watch(activeId, () => loadProducts(true))` 切换分类重置分页
- 点击分类项 → `van-sidebar-item` 自动激活

```ts
async function loadProducts(reset = false) {
  if (reset) { page.value = 1; products.value = []; finished.value = false }
  const res = await listProducts({
    categoryId: activeId.value,
    page: page.value,
    pageSize: 10
  })
  products.value.push(...res.list)
  if (!res.hasMore) finished.value = true
  else page.value += 1
}
```

## 4. 商品详情（ProductDetailView）

文件：`client/src/views/ProductDetailView.vue`

- 路由：`/product/:id`
- 加载：`onMounted` → `getProduct(route.params.id)`
- 显示：
  - 封面（`van-image`）
  - 价格（现价 + 原价划线）+ 销量 + 库存
  - 商品介绍（`van-cell title="商品介绍"` + description）
  - 图片列表（`van-image` 多张）
- 操作：
  - 「加入购物车」→ `cart.add(productId, 1)` + `showToast`
  - 「立即购买」→ `router.push(\`/order/confirm?productId=${id}&quantity=1\`)`

## 5. 购物车（CartView）

文件：`client/src/views/CartView.vue`

- `useCartStore()` 取购物车
- 每行结构：`<van-checkbox v-model="r.selected" />` + 封面 + 标题 + stepper + 删除
- 顶部全选：`van-checkbox v-model="allChecked"`（store 中的双向 computed）
- 底部：`van-submit-bar` 显示总金额（`totalPrice` × 100 = 分）+ 「结算」
- 结算：跳 `/order/confirm`

```ts
const totalPrice = computed(() =>

)

function checkout() {
```

## 7. 下单成功（OrderSuccessView）

文件：`client/src/views/OrderSuccessView.vue`

- 从 `route.query.id` 读订单 ID 展示
- 操作按钮：
  - 「查看订单」→ `router.push(\`/order/detail?id=${...}\`)` —— **注意**：订单详情用 `id`，不是 `orderNo`
  - 「继续购物」→ `router.push('/home')`

> 当前演示版的「查看订单」按钮需要从 `orderNo` 反查 `id`，但 query 字段约定是 `id`。生产化阶段建议统一传 `id`。

## 9. 订单详情（OrderDetailView）

文件：`client/src/views/OrderDetailView.vue`

- 从 `route.query.id` 读订单 ID
- 加载：`getOrder(id)`，渲染：
  - 状态进度条（按 `status` 变色）
  - 收货人
  - 商品列表（items）
  - 订单信息（订单号 / 创建时间 / 支付时间 / 物流单号）
- 操作（按状态）：
  - `PENDING (0)` → 「取消订单」
  - `PAID (1)` → 「取消订单」+ 「提醒发货（toast 占位）」
  - `SHIPPED (2)` → 「确认收货」
  - 其他 → 仅展示

```ts
async function cancelOrder() {
  await showConfirmDialog({ title: '取消订单', message: '确定取消？' })
  await cancelOrderApi(order.value!.id)
  showToast('已取消')
  load()
}

async function confirmReceipt() {
  await showConfirmDialog({ title: '确认收货', message: '确认已收到货？' })
  await confirmReceiptApi(order.value!.id)
  showToast('已确认')
  load()
}
```

## 10. 我的（ProfileView）

文件：`client/src/views/ProfileView.vue`

UI 结构：

```
van-nav-bar (title="我的")
用户卡片：头像 + 昵称 + 账号 + 手机号
van-cell-group inset
  van-cell (icon=orders-o) 我的订单 → /order/list
  van-cell (icon=balance-o) 优惠券
  van-cell (icon=location-o) 收货地址（Phase 2 占开发）
  van-cell (icon=service-o) 客户服务（toast 占位）
退出登录按钮 → showConfirmDialog + userStore.logout()
```

要点：

- 头像 / 昵称 / 手机号从 `userStore.user` 读，没有则用默认 placeholder
- 菜单列表（共 5 项）：
  - 我的订单 → `/order/list`
  - 我的退款 → `/refunds/my`
  - 优惠券 → `/coupons`（含 `listMyCoupons` 实时拿可用张数）
  - 收货地址 → Phase 2 待开发（保留菜单项 + 「待开发」提示）
  - 客户服务 → 弹 Toast 占位
- 退出登录：`userStore.logout()` → 清 localStorage → 跳 `/login`

## 11. 登录（LoginView）

文件：`client/src/views/LoginView.vue`

- 表单：用户名 + 密码（无验证码 / 短信）
- 提交：`userStore.login(form)` → 成功后按 `redirect` query 跳转
- **真实版**：调用 `/api/auth/login`，经 `AuthService.login` bcrypt 比对；只有 seed 写入的 5 个测试账号（`alice~eve / user123`）能成功

```ts
async function onSubmit() {
  if (!form.username || !form.password) {
    showToast('请输入用户名和密码')
    return
  }
  submitting.value = true
  try {
    await userStore.login(form)
    showToast({ type: 'success', message: '登录成功' })
    const redirect = (route.query.redirect as string) || '/home'
    router.replace(redirect)
  } catch (e) {
    const msg = e instanceof Error ? e.message : '登录失败'
    showToast(msg)
  } finally {
    submitting.value = false
  }
}
```
