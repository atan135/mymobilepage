# 07 内容管理（轮播图 + 公告）

> 两个体量小的内容管理模块合并到一份文档里：首页轮播图 + 首页公告。

## 1. 模块定位

| 子模块 | 用途 |
| --- | --- |
| 轮播图管理 | 维护移动端首页顶部的轮播图（图片 + 可选跳转链接） |
| 公告管理 | 维护首页公告列表（草稿 / 已发布两种状态） |

## 2. 涉及数据表

| 表 | 用途 |
| --- | --- |
| `banners` | 轮播图 |
| `announcements` | 公告 |

详见 `10-服务端/03-数据库Schema说明.md`。

## 3. Server 接口清单

### 轮播图（`server/src/admin-banners/`）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| `GET` | `/api/admin/banners` | `banner:list` | 列表（全部，含 disabled） |
| `GET` | `/api/admin/banners/:id` | `banner:list` | 详情 |
| `POST` | `/api/admin/banners` | `banner:create` | 创建 |
| `PATCH` | `/api/admin/banners/:id` | `banner:edit` | 更新 |
| `DELETE` | `/api/admin/banners/:id` | （未挂权限装饰器） | 删除 |

DTO（`admin-banners/dto/banner.dto.ts`）：

```ts
export class CreateBannerDto {
  @IsString() @MaxLength(500) image!: string
  @IsOptional() @IsString() @MaxLength(500) link?: string
  @IsOptional() @IsInt() @Min(0) sort?: number
  @IsOptional() @IsBoolean() enabled?: boolean
}
```

### 公告（`server/src/admin-announcements/`）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| `GET` | `/api/admin/announcements` | `announcement:list` | 列表 |
| `GET` | `/api/admin/announcements/:id` | `announcement:list` | 详情 |
| `POST` | `/api/admin/announcements` | `announcement:create` | 创建 |
| `PATCH` | `/api/admin/announcements/:id` | `announcement:edit` | 更新 |
| `PATCH` | `/api/admin/announcements/:id/publish` | `announcement:publish` | 发布 |
| `PATCH` | `/api/admin/announcements/:id/unpublish` | `announcement:publish` | 下架 |
| `DELETE` | `/api/admin/announcements/:id` | `announcement:delete` | 删除 |

DTO（`admin-announcements/dto/announcement.dto.ts`）：

```ts
export class CreateAnnouncementDto {
  @IsString() @MaxLength(128) title!: string
  @IsString() @MaxLength(5000) content!: string
  @IsOptional() @IsString() @MaxLength(500) link?: string
  @IsOptional() @IsInt() @Min(0) sort?: number
  @IsOptional() @IsIn([0, 1]) status?: number     // 0 草稿 / 1 已发布
}
```

`publish` / `unpublish` 在 service 层的实现：

```ts
async publish(id: number) {
  const a = await this.findOne(id)
  return this.prisma.announcement.update({
    where: { id: a.id },
    data: { status: 1, publishedAt: a.publishedAt ?? new Date() }   // 首次发布写时间，后续发布保留
  })
}

async unpublish(id: number) {
  await this.findOne(id)
  return this.prisma.announcement.update({
    where: { id },
    data: { status: 0 }
  })
}
```

## 4. Admin 路由与页面

### 轮播图

- **路由**：`/banners`
- **权限**：`banner:list`
- **文件**：`admin/src/views/BannerListView.vue`

布局：

- 表格：ID / 图片（缩略图）/ 链接 / 排序 / **启用（el-tag，success=启用 / info=停用）** / 创建时间 / 操作（编辑 / 删除）
- 新建 / 编辑 Dialog：图片 URL / 跳转链接 / 排序 / 是否启用（**Dialog 内用 el-switch**；表格内仅展示状态）

### 公告

- **路由**：`/announcements`
- **权限**：`announcement:list`
- **文件**：`admin/src/views/AnnouncementListView.vue`

布局：

- 表格：ID / 标题（overflow-tooltip）/ 内容（2 行截断）/ 链接 / 排序 / 状态（草稿 / 已发布 tag）/ 发布时间 / 操作（编辑 / 发布 / 下架 / 删除）
- 新建 / 编辑 Dialog：标题 / 内容（textarea 5000 字带字数统计）/ 跳转链接 / 排序 / 状态（草稿 / 立即发布）

## 5. 客户端如何使用

### 轮播图（`server/src/client-banners/client-banners.controller.ts`）

```ts
@Get()
async list() {
  return this.prisma.banner.findMany({
    where: { enabled: true },
    orderBy: [{ sort: 'asc' }, { id: 'asc' }],
    select: { id: true, image: true, link: true }   // 精简字段
  })
}
```

- 公开端点，无守卫
- 仅返回 `enabled = true` 的项
- 移动端首页调用（`client/src/views/HomeView.vue` 的 `loadBanners`）

### 公告

> **当前未在客户端暴露**。roadmap 1.9 的目标是「后台能维护 + 移动端首页能展示」，但实际 `client` 端未实现公告读取。如需启用：
>
> - 服务端新增 `server/src/client-announcements/`，提供 `GET /api/announcements`（仅 `status = 1`）
> - 移动端首页 / ProfileView 增加公告列表组件

## 6. 权限点

### 轮播图

| 权限码 | 用途 |
| --- | --- |
| `banner:list` | 路由 + 列表 / 详情 |
| `banner:create` | 新建按钮 + 接口 |
| `banner:edit` | 编辑按钮 + 接口 |
| `banner:delete` | 删除按钮（接口未挂权限装饰器） |

### 公告

| 权限码 | 用途 |
| --- | --- |
| `announcement:list` | 路由 + 列表 / 详情 |
| `announcement:create` | 新建 |
| `announcement:edit` | 编辑 |
| `announcement:publish` | 发布 / 下架 |
| `announcement:delete` | 删除 |

`ADMIN` 默认包含：`list / create / edit / publish`（不包含 `delete`）。`delete` 仅 `SUPER_ADMIN`。

## 7. 边界与注意

- 图片 URL：当前阶段都是外链（seed 用 `picsum.photos`）。**正式上线需要**：上传服务（OSS / MinIO）+ 后台接入上传组件 + URL 校验
- 公告链接字段 `link`：演示版未消费，建议格式 `/pages/notice/<id>`（移动端路由）
- 删除轮播图：直接 `delete`，**无外键引用保护**（没有 `Banner` 外键的子表）
