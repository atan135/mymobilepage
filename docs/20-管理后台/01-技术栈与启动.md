# 01 管理后台技术栈与启动

> `admin/` 子项目的技术栈、目录约定、启动与构建。

## 1. 技术栈

| 维度 | 选型 |

## 2. 入口与全局设置

文件：`admin/src/main.ts`

```ts
const app = createApp(App)

const pinia = createPinia()
pinia.use(piniaPersistedstate)
app.use(pinia)

// 在挂载之前初始化主题，避免页面闪烁
useThemeStore()

for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component as never)
}

app.use(ElementPlus, { locale: zhCn })
app.directive('permission', permissionDirective)
app.use(router)

app.mount('#app')
```

要点：

- **Pinia 持久化**通过 `pinia-plugin-persistedstate`，在 `admin-auth.ts` 的 store 定义里 `persist: { key: 'admin-auth', paths: ['token', 'user'] }` 显式声明
- **主题 store**在挂载前初始化（`useThemeStore()`），避免页面闪烁
- **Element Plus Icons 全量注册**为全局组件，模板里直接用 `<el-icon><House /></el-icon>` 或 `:is="'House'"`
- **`v-permission` 指令**全局注册（详见 `02-账号权限与登录.md`）

## 3. 路由与守卫

文件：`admin/src/router/index.ts`

### 路由结构

```
/login                            LoginView              requiresAuth: false
/                                 AdminLayout            requiresAuth: true
  ├─ /dashboard                   DashboardView          permission: dashboard:view
  ├─ /users                       UserListView           permission: user:list
  ├─ /categories                  CategoryListView       permission: category:list
  ├─ /products                    ProductListView        permission: product:list
  ├─ /orders                      OrderListView          permission: order:list
  ├─ /banners                     BannerListView         permission: banner:list
  └─ /announcements               AnnouncementListView   permission: announcement:list
```

### 全局前置守卫

```ts
router.beforeEach((to) => {
  const auth = useAdminAuthStore()
  const requiresAuth = to.meta.requiresAuth !== false

  if (requiresAuth && !auth.isLoggedIn) {
    return { name: 'login', query: { redirect: to.fullPath } }
  }

  if (to.name === 'login' && auth.isLoggedIn) {
    return { name: 'dashboard' }
  }

  const perm = to.meta.permission
  if (typeof perm === 'string' && !auth.hasPermission(perm)) {
    return { name: 'dashboard' }
  }

  if (typeof to.meta.title === 'string') {
    document.title = `${to.meta.title} · 管理后台`
  }
})
```

三道关：

1. **未登录** → 跳 `/login`，带 `redirect` query
2. **已登录访问 `/login`** → 跳 `/dashboard`
3. **路由 meta.permission 校验** → 没有该权限跳 `/dashboard`（不弹窗）

## 4. 自定义指令：v-permission

文件：`admin/src/directives/permission.ts`

```ts
const permission: Directive<HTMLElement, string | string[] | undefined> = {
  mounted(el, binding) {
    const auth = useAdminAuthStore()
    const { value } = binding

    if (!auth.isLoggedIn) { hide(el); return }
    if (value === undefined) return

    const allowed = Array.isArray(value)
      ? value.some((p) => auth.hasPermission(p))
      : auth.hasPermission(value)

    if (!allowed) hide(el)
  }
}

function hide(el) { el.parentElement?.removeChild(el) }
```

用法：

```vue
<el-button v-permission="'product:create'">新建商品</el-button>
<el-button v-permission="['banner:create', 'banner:edit']">操作</el-button>
```

> 实现是「没权限就移除 DOM」，不是 `display: none`。优点：彻底不影响布局；缺点：DOM 不存在导致测试时选不到。

## 5. HTTP 封装

文件：`admin/src/api/request.ts`

```ts
export const request = ofetch.create({
  baseURL: '/api/admin',
  timeout: 10_000,
  onRequest({ options }) {
    const token = localStorage.getItem('admin-token')
    if (token) {
      const headers = new Headers(options.headers as HeadersInit | undefined)
      headers.set('Authorization', `Bearer ${token}`)
      options.headers = headers
    }
  },
  onResponseError({ response }) {
    if (response.status === 401) {
      localStorage.removeItem('admin-token')
      localStorage.removeItem('admin-user')
    }
  }
})
```

要点：

- `baseURL = '/api/admin'` — 所有 API 都自动追加该前缀
- 自动注入 `Authorization: Bearer <token>`
- 收到 401 自动清掉本地 token + user，但**不会自动跳登录**（路由守卫会接管）
- 超时 10 秒

## 6. 启动与构建

通过根 `package.json` 的 workspaces 调用：

```bash
npm run dev:admin           # 开发（Vite dev server）
npm run build:admin         # 构建到 admin/dist
npm run preview:admin       # 预览构建产物
npm run type-check:admin    # 类型检查
```

Vite 配置（`admin/vite.config.ts`）：

- 端口：`5174`
- 主机：`0.0.0.0`（局域网可访问）
- 代理：`/api` → `http://localhost:3000`
- 自动导入：`unplugin-vue-components` + `ElementPlusResolver`；`unplugin-auto-import` 同
- 别名：`@` → `src/`

## 7. 主题

文件：`admin/src/stores/theme.ts`

- 三态：`light` / `dark` / `system`
- Element Plus 暗黑模式通过 `html.dark` 类切换（`element-plus/dist/index.css` + `theme-chalk/dark/css-vars.css`）
- 切换时给 `<html>` 加短暂 `theme-transition` class，220ms 后移除（避免长期 transition 性能损耗）
- 顶栏主题下拉框触发（`AdminLayout.vue`）
