# 00 总览与入门

> 项目级通用文档。新成员入职请按本章节顺序阅读。

## 文档清单

| 文件 | 内容 |
| --- | --- |
| `01-项目总览.md` | 三端定位（client / admin / server）+ 技术栈一览 |
| `02-快速开始.md` | 安装依赖、三端启动命令、Seed 数据、默认账号 |
| `03-架构与目录结构.md` | Monorepo 布局、数据流图（前台/后台/服务端协作） |
| `04-开发约定与常见问题.md` | 命名规范、commit 规范、已知坑、FAQ |

## 阅读建议

1. 先读 `01-项目总览.md` 了解项目是什么、技术栈是什么
2. 再读 `02-快速开始.md` 把三端跑起来
3. `03-架构与目录结构.md` 在你熟悉代码前可以先扫一遍，有疑问时回查
4. `04-开发约定与常见问题.md` 遇到坑位或规范问题时查阅
